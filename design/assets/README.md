# Shelfie design assets

Static SVGs drawn from the design canvas and the prototype. Colours are only the 16-colour palette in `../tokens.json` and its tints (the gauge track is Ledge Wood at 45% on white, `#e9d6c4`). No fonts are used in any file.

| Folder        | Files                                                                                                                                                | Use                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `mascot/`     | `jar-{happy,party,worried,sleepy}.svg`, and the same with `-on-ledge`; `shelfie-icon.png` (the source image) and `shelfie-icon.svg` (the master)     | The jar and its four moods. The ledge versions are for hero and empty states; on screens only the mascot stands on a ledge. Static: the prototype's bobbing, blinking and confetti animation is not included. `shelfie-icon.svg` is the app icon (the happy jar on Leaf Mist); `public/favicon.svg` and `site/site-assets/favicon.svg` are small-size versions of it (no side leaves, gauge, highlights; bigger eyes), and the PNG icons in `public/` are rendered from it by hand. |
| `containers/` | One icon per unit in the prototype's unit list (34 units), each as `<unit>.svg` (70% left) and `<unit>-low.svg` (15% left, coral), plus `units.json` | Little jars. The file name is the unit name, so the app can look an icon up directly. `units.json` lists every unit with its group (Containers, Packs & rolls, Tools & cloths, Counted items), label and files. A unit someone types in themselves has no icon: use `box.svg`.                                                                                                                                                                                                      |
| `status/`     | `gauge-ok, gauge-low, clock, expired`                                                                                                                | The 16px icons inside the one chip on a card.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `icons/`      | category, privacy and small UI icons                                                                                                                 | From the landing page. Teal line icons, 32px.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `background/` | `leaves-corners.svg` (1400x900, full page), `leaves-top-right.svg`, `leaves-bottom-left.svg`                                                         | Botanical Leaves, drawn in the corners over Leaf Mist (`--bg`). Transparent, so the flat page colour shows through.                                                                                                                                                                                                                                                                                                                                                                 |

In the app the little jars have a live gauge, so step 4 draws them as a React component from the same shapes; these files are the reference and are used directly for the landing page, README, store listing and docs.
